CoCreate Server Load Test

A dependency-free Node.js client for measuring HTTP, HTTPS, file download, and CoCreate socket workloads from a separate load-generator node. The target server remains responsible for its own resource and autoscaling telemetry.

Requirements and setup

Use Node.js 22.4 or newer. Clone this repository on a machine separate from the target:

npm run setup

Setup writes a local cocreate-server-loadtest.config.json with restricted file permissions. No dependency installation is required; the runner uses Node's built-in fetch, WebSocket, and worker threads.

HTTP requests

Set LOAD_MODE=http-get, HTTP_URL, RATE, and DURATION_SECONDS to load a health, API, or file endpoint. Response bodies are read so byte counts and transfer latency are included. POST workloads require LOAD_MODE=http-post and explicit ALLOW_HTTP_POST=YES. 

LOAD_MODE=http-get HTTP_URL=https://api.example.com/health RATE=5 DURATION_SECONDS=30 npm run load

CoCreate envelope workloads

Use LOAD_MODE=envelope with an ENVELOPE_JSON or ENVELOPE_FILE payload. Read requests are allowed by default. Other methods require ALLOW_ENVELOPE_WRITES=YES. Set SOCKET_CLIENTS to control concurrent client connections; RATE is the total request start rate across those clients.

Use representative bounded reads and disposable data for writes. The client does not create or clean up records automatically.

Phases and results

PROFILE_JSON can sequence warmup, baseline, ramp, burst, and cooldown phases. Optional HEALTH_URL and OBSERVATION_URL polling records availability and external JSON snapshots. Set RESULT_FILE for a JSON summary and SAMPLES_FILE for per-request JSONL records.

Correlate client timestamps, latency, throughput, errors, and health interruptions with server-side worker, CPU, memory, replica, and autoscaler telemetry. Keep the generator's host and capacity consistent between comparisons and ensure it is not saturated.
